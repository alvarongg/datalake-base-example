# Iconos de arquitectura de AWS

Los archivos `.svg` de esta carpeta son iconos oficiales de servicio de
[AWS Architecture Icons](https://aws.amazon.com/architecture/icons/) (paquete
Icon-package_07312026, tamaño 48). Su uso está sujeto a los términos de AWS
(permitidos para diagramas de arquitectura que representen servicios de AWS;
no modificar ni usar para sugerir patrocinio de AWS). Para actualizarlos,
descarga el paquete desde esa página y reemplaza los archivos.
